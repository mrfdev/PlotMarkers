with JVM attribute 25. Compilation stays on Oracle JDK `25.0.4.1+1-LTS-5`, Java 25 bytecode. The installed
server runtime is Oracle HotSpot `27+35-2325` (macOS aarch64).

The [global](https://docs.papermc.io/paper/reference/global-configuration/) and

## Verification and deployment

The full `./scripts/rebuild.sh` clean build and all configured verification tasks
passed on JDK 25.0.4.1, including `docsCheck`. `-Xlint:deprecation -Werror` produced
no compiler deprecation warnings. Unit tests: `NO-SOURCE` (none exist).
Shell syntax checks passed. The launcher rejects legacy/extra arguments and a
missing pinned server JAR without starting Java or selecting a fallback.

Both artifacts contain the expected plugin descriptor, generated metadata, and
Mojang mappings namespace. Each has seven plugin classes at major 69; all 93
classes in the shaded JAR are major 69 or lower. Neither artifact contains
preview bytecode. Both retain semantic plugin version 2.0.4 and release build 032.

| Java 27 smoke test | Shaded JAR | Thin JAR with external-library fixture |
| --- | --- | --- |
| Paper `26.3-41-main@a15fed9`, API `26.3.build.41-alpha` | PASS | PASS |
| Plugin enable, diagnostics, invalid-command usage, world generator | PASS | PASS |
| 361 POIs and 114 shapes over BlueMap HTTP | PASS | PASS |
| BlueMap reload with unchanged marker content | PASS | PASS |
| All four dimensions saved, plugin disable, process exit 0 | PASS | PASS |

The shaded test used the maintained `1MB-minecraft.sh`; the thin test used
`scripts/start-test-server.sh`, including its pinned SHA-256 check. PaperScript's
post-run `verify` also matched fresh official build metadata. The thin fixture
and thin JAR were removed from the active instance afterward, and the exact
tested shaded JAR was restored.

Marker JSON was identical to the historical Paper 26.2 fixture, with canonical
SHA-256 `0f826e5f571dc4417b7032bc6617fa1ff2a5ff9209cab906e2fe6724c1109e4a`.
Both successful runs had no error-level messages, linkage/class-version failures,
PlotMarkers exceptions, or scheduled-task/shutdown failures.

The initial harness run passed startup, commands, HTTP markers, reload, and exited
0, but its final assertion expected Paper 26.2's old shutdown log phrase. The
harness was corrected to require Paper 26.3's completed region I/O and per-world
I/O shutdown for all four dimensions. The shaded test then passed in full;
version and build numbers were reused.

Remaining third-party notices: OSHI cannot name macOS 27; LuckPerms Commodore 2.2
reflectively mutates a Brigadier final field under Java 27; WorldGuardExtraFlags
registers deprecated PlayerSpawnLocationEvent; BlueMap uses fallback metadata for
`minecraft:builders`; a plugin requests a save while autosave is enabled. The
LuckPerms warning was not hidden with a permissive JVM flag. These notices did not
prevent the tested behavior and are not claimed resolved.

Manual gameplay remains untested: an actual player joining, the browser map's
visual presentation, and live claim/delete/merge/unlink/transfer and quit/kick
marker updates. No shared-server runtime test was performed.
